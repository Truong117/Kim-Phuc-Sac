# Weekly Planning V3 Phase 7B.2A browser E2E evidence

## Scope and isolation

This branch is based on `origin/staging` at `ad6cb35398c5b88515889ce7824f69dd2d4e427b`, the merge commit for PR #70. The local browser runner uses pinned `@playwright/test@1.64.1` and Playwright managed Chromium `156.0.8078.4`. It starts Vite at `127.0.0.1:5174` and Laravel at `127.0.0.1:8001` with a dedicated SQLite database and synthetic `.test` accounts. No staging or production connection, TiDB migration, deployment, or rollout occurred. PR #70's head CI run `41163894141` succeeded; CI on the merge commit itself was not separately verified.

Copy the reviewed example profile to `backend/.env.weekly-planning-v3-e2e` and inspect it locally; never copy it over `backend/.env`. After the approved package and managed Chromium are installed, run `npm run test:e2e` from the repository root. The runner checks loopback ports, verifies the effective Laravel configuration and canonical database/storage paths, rejects cached configuration and unverified existing databases, creates the exact disposable fixture, starts hidden local processes, runs Chromium, then stops those processes and removes only the verified fixture. The browser checks the backend's guarded response header before proceeding. `backend/.env` is not modified. Test artifacts are ignored under `test-results/`; the published synthetic-plan screenshot is `test-results/evidence/v3-published-synthetic.png`. Failure traces, screenshots, and video remain under `test-results/artifacts/` for local diagnosis and must not be shared without review because traces can include synthetic login requests.

The fixtures use one synthetic organization, HR, Assistant, OWNER, and four employee accounts; the browser plan selects three. The browser test checks the UI and reads scoped aggregate database state through a restricted, preflight-guarded assertion script. The assertion script accepts only a positive plan ID and exposes no mutation or general SQL interface. Cleanup reported PASS after the completed run.
